打包命令

推荐直接运行仓库根目录下的 `build.bat`。

如需手动执行：

python -m venv .venv_build
.venv_build\Scripts\python.exe -m pip install --upgrade pip
.venv_build\Scripts\python.exe -m pip install -r requirements.txt pyinstaller
.venv_build\Scripts\python.exe -m PyInstaller hantokana.spec

说明：
- 打包建议使用独立虚拟环境，避免全局 site-packages 里的旧包影响 PyInstaller。
- 运行时依赖放在 `requirements.txt`，打包时额外安装 `PyInstaller`。
